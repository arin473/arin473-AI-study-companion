# arin473-AI-study-companion
AI Study Companion is an AI-powered learning platform that helps students study smarter through educational content analysis, source-based answers, and personalized learning progress tracking.
AI Study Companion

Project Overview

AI Study Companion is an AI-powered learning application designed to help students study more effectively using their academic PDFs. It uses multimodal PDF ingestion to process study materials and aims to provide answers grounded in the uploaded content.

Features

- PDF upload and ingestion.
- Processing of academic study materials.
- AI-powered question answering based on uploaded documents.
- Source-grounded learning assistance.
- User-friendly interface for studying academic content.
